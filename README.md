# compound_interest.py
A simple Python program to calculate the total amount of compound interest based on the principal rate, number of times compounded per year, and time period
#Features
input-->Takes principal amount 
input-->Takes interest rate 
Takes the number of times interest is compounded per year
Takes time period in years
Calculates the total amount
Calculates the compound interest
#Formula
Amount = P × (1 + r/n)^(n×t)
#How to Run
Clone or download this repository.
Run the Python file:-
python compound_interest.py

Enter principal amount10000
Enter interest rate (%)2
Enter number of times compounded per year1
Enter time in years2
